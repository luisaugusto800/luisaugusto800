### 👨‍💻 Sobre Mim

Desenvolvedor de software com sólida base prática e acadêmica, focado no desenvolvimento de sistemas escaláveis, performáticos e bem arquitetados. Experiência na criação de ecossistemas completos — desde a concepção de **arquiteturas de backend corporativas** e modelagem de dados relacionais até a entrega de **aplicativos mobile** e **interfaces web modernas**.

- 🎓 **Formação:** Cursando **Análise e Desenvolvimento de Sistemas (ADS)** na **Unisinos**.
- 🏗️ **Arquitetura & Engenharia:** Aplicação prática de **Clean Architecture / DDD**, desenvolvimento de APIs REST seguras e modelagem relacional avançada.
- 📱 **Full Stack & Mobile:** Desenvolvimento de soluções completas com **.NET 9 / C#**, **Node.js (TypeScript)**, **React Native (Expo)** e **React + Vite**.
